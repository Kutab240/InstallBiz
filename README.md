# File Downloader Service

Сервис для скачивания каталога текстовых файлов через внешний API и анализа их содержимого.

Написан на **Python 3.12** с использованием **FastAPI** и **asyncio**.

---

## Стек технологий

| Технология | Назначение |
|---|---|
| FastAPI | Веб-фреймворк, REST API |
| uvicorn | ASGI-сервер |
| httpx | Асинхронный HTTP-клиент |
| Pydantic | Валидация данных и модели |
| asyncio | Асинхронное скачивание |
| zipfile | Распаковка ZIP-ответов |

---

## Архитектура

Проект построен по паттерну **Service Layer**:

```
main.py                  — FastAPI приложение и роуты
models.py                — Pydantic модели данных
services/
  downloader.py          — сервис скачивания файлов через API
  calculator.py          — сервис расчёта статистики по цифрам
static/
  index.html             — веб-интерфейс
```

---

## Запуск

### Через Docker (рекомендуется)

```bash
docker-compose up --build
```

### Без Docker

```bash
pip install -r requirements.txt
uvicorn main:app --port 3001
```

Откройте в браузере: **http://localhost:3001**

---

## API документация

После запуска доступна интерактивная Swagger документация:

**http://localhost:3001/docs**

### Эндпоинты

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/download` | Запустить скачивание каталога |
| GET | `/api/progress` | Получить статус скачивания |
| GET | `/api/files` | Список скачанных файлов (пагинация) |
| POST | `/api/calculate` | Расчёт статистики по выбранным файлам |

---

## Функциональность

### Скачивание
- Асинхронное скачивание файлов партиями по 3 штуки
- Автоматическая обработка rate-limit: пауза при `429`/`403` с учётом заголовка `Retry-After`
- Отображение прогресса в реальном времени (время старта по НСК, UTC+7)

### Веб-интерфейс
- **Страница скачивания** — кнопка запуска, прогресс-индикатор
- **Страница файлов** — список с пагинацией, сортировка по времени загрузки
- Выбор файлов: точечно, вся страница, все сразу
- Расчёт статистики: сколько раз встретилась каждая цифра 0–9 — общая и по каждому файлу
