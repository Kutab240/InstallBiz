# File Downloader Service

Сервис скачивания и анализа файлов через API. Написан на Python (FastAPI).

## Запуск через Docker

```bash
docker-compose up --build
```

Откройте в браузере: http://localhost:3001

## Запуск без Docker

```bash
pip install -r requirements.txt
uvicorn main:app --port 3001
```

Откройте в браузере: http://localhost:3001

## Функциональность

- Асинхронное скачивание файлов через API (asyncio + httpx)
- Обработка rate-limit: автопауза при 429/403 с учётом Retry-After
- Прогресс в реальном времени (время старта по НСК)
- Список скачанных файлов с пагинацией и сортировкой по времени
- Выбор файлов (точечно / вся страница / все)
- Расчёт статистики по цифрам 0–9: общая и по каждому файлу
